# 青娥鱼 · bili-whale-qq

面向本机或自管服务器的B站与QQ群AI助手，提供WebUI、DSH插件、联网研究、书库片段检索、日记和云端语音。

本仓库是独立整理的公开源码版本，不包含私人部署的账号、聊天历史、知识库、音色、表情包或旧Git历史。

## 功能

| 模块 | 能力 |
| --- | --- |
| QQ | 群白名单、管理员权限、概率回复、图片识别、拆句、表情、短回复语音 |
| B站 | 视频资料读取、评论与楼中楼、@提醒、私信收件、选片与分享 |
| 检索 | Wiki、网页和B站交叉检索，按实际取得的正文回答 |
| 书库 | 本地TXT/PDF/DOC等资料按需导入，多维标签和片段检索；部分格式需另装解析工具 |
| 日记 | 文言日记、缺稿补写、跨日生成，可配置发布专栏及文集 |
| 管理 | WebUI完整设置、日志诊断、表情库、语音试听，DSH或独立模式 |

## 环境

- 推荐Windows x64与Node.js 24。
- 当前QQ接入按Windows桌面QQ与SnowLuma实现，均需自行安装和登录；本仓库不分发其程序。Linux需要另行适配QQ接入。
- QQ和SnowLuma使用同一个Windows用户、匹配的运行权限。
- 文本、视觉和语音模型按提供方配置，外部API可能收费。云端CosyVoice不需要本地GPU。
- 书库脚本使用Python 3，PDF/DOCX/旧DOC等格式分别依赖相应解析库或转换工具；见[书库说明](docs/BOOKS.md)。

## 快速开始

在本仓库目录执行：

```powershell
node --version
Copy-Item config.example.json config.json
node src/server.mjs --no-services
```

已有配置时不要覆盖。访问 `http://127.0.0.1:7788`，先检查界面并填写自己的模型、OneBot连接、QQ群和管理员设置。

示例不预置账号、管理员、群或音色；自动分享、评论巡检、私信巡检和日记发布默认关闭。语气指令默认留空。示例令牌只引用环境变量或留空，不是可用凭据。

准备好QQ和SnowLuma后，退出仅界面模式，再启动业务：

```powershell
$env:SNOWLUMA_DIR='C:\apps\snowluma'
npm start
```

`npm start`尝试启动SnowLuma和业务Agent，按保存设置运行。也可使用DSH托管，参见[插件说明](dsh-plugin/README.md)。同一账号只启用一个业务实例；WebUI检测到DSH后跟随其配置和状态，“让位”应先排查已有实例。

## 配置与数据

| 路径 | 用途 |
| --- | --- |
| `config.json` | 私有账号与业务设置，忽略提交 |
| `.data/` | 记忆、状态、去重、额度、设置备份和诊断，忽略提交 |
| `book/` | 自行提供的书籍和索引，忽略提交 |
| `words/` | 日记，忽略提交 |
| `biaoqingbao/` | 自行提供且有权使用的表情，忽略提交 |

`BILI_WHALE_DATA`可指定数据目录；`SNOWLUMA_DIR`可指定QQ接入程序目录。支持的密钥字段可填 `env:变量名`，启动进程需继承变量。填写OneBot HTTP令牌后，WebSocket可使用兼容的令牌配置，具体以连接器和WebUI设置为准。

不要提交真实密钥、Cookie、聊天记录或用户资料。MIT许可只覆盖本项目及随附许可允许的源码，不授予第三方音色、书籍或角色素材的权利。

## 回复、语音与表情

普通文字与图片共用概率选择；@、叫名字和明确任务等有独立触发规则。长文字可按句意拆为最多三条。表情按语境和图库设置选择，同图重复间隔可调。

QQ原生语音或CosyVoice短语音成功后均可按现有规则发表情。未知回执不盲目补发，图片失败不重发已成功语音。语音试听在WebUI生成，最多200字，调用云端计费但不发QQ群。

音色ID必须匹配模型和地域。留空语气指令不添加情绪要求；响度增强可单独关闭，以保留云端返回的音频字节。公开版额外增益默认0，无内置音色或录音。

自动B站浏览有温和间隔、小时额度和风控冷却，默认不启用自动分享。数据采集依赖平台提供的资料，不保证取得每个视频的字幕或画面。

## 日记与迁移

日记依据已留存的QQ群和B站记录生成，不包括QQ私聊；文言正文与标题合计最多3000个非空白字符。需要自行启用补写和投稿。未知投稿回执先核对，不直接重投。

迁移时另行安全复制配置、数据、书库和表情，并调整绝对路径。切换前停旧实例，避免重复回复。更新前备份数据、暂停业务、检查工作区，再拉取代码并按原方式重启；不强制覆盖服务器本机改动。


默认测试是隔离的离线烟雾回归，不会向QQ/B站发消息。更多专项入口见 `package.json`。书库测试需要Python；外部服务实际兼容性须使用自己的测试环境验证。
