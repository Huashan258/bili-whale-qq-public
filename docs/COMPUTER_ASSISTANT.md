# Windows本机助手

版本v0.3.0。本机查询computer.enabled与按钮computer.allowActions默认关闭。通过电脑工作台配置真实机器人管理员、Maa安装目录、允许读取的绝对目录和截图进程名单后使用。管理员身份按真实QQ UID核验；群管理不会自动获得本机控制权限。

## 指令

程序查询：Maa运行状态
程序查询：Maa运行状态，截图
程序截图：Maa
程序查询：QQ
系统查询：CPU、内存、网络流量
文件列表：C:\apps
文件读取：C:\apps\README.md
程序操作：Maa 勾选自动肉鸽
程序操作：Maa 取消自动肉鸽
程序操作：Maa 开始
程序操作：Maa 停止

默认私聊返回；开启computer.groupResults后，白名单群的程序/系统查询、程序截图和Maa操作结果直接发到原群。文件内容与目录列表仍私聊，私聊请求仍在私聊返回。确定指令不依赖聊天概率、不进行联网或模型调用；不把文件或窗口内容放入模型上下文。只读已允许目录中的文本，拒绝路径越界、链接越界和常见凭据文件；最大2MiB，只返回前4000字符。PDF/Word等二进制文档暂不支持。

Maa任务状态读取实时Windows UI Automation控件，进程存在不等于任务运行。操作只匹配明确白名单动作，开始会运行当前勾选的整套任务。有弹窗、控件不可用/不唯一或多个实例时拒绝，不盲点坐标。先保存操作消息回执，跨重启不重复派发，超过两分钟历史操作不补执行。

截图仅限允许名单的程序窗口，最小化、锁屏、空白或不可访问时提示失败；临时PNG读入后清除。CPU为系统性能计数，内存为物理内存，网卡显示采样速率及启动/重置以来累计，不代表今日或运营商计费流量。

需要Windows交互桌面及匹配的程序权限。部署服务器后查询服务器本身；本版本没有访问家中电脑的远程代理。WebUI只监听127.0.0.1，不应直接公开到互联网。

实现：src/computer-control.mjs、scripts/computer-bridge.ps1（UTF-8 BOM）、src/chat.mjs。验证：npm run test:computer，使用临时文件和模拟QQ，不操作真实Maa。
