# 公开版整理说明

本版本从代码快照整理，使用全新Git历史，不连接原私有仓库。

- 移除内部交接、聊天示例记录、私人研究与部署文档，改用通用安装说明。
- 不含真实配置、Cookie、令牌、账号管理员、群名单、音色ID、书籍、日记、表情和运行数据。
- 代码与测试中的私人账号示例替换为合成fixture值，示例配置目的地全部留空。
- 移除社区角色图片及其专属素材声明，换成新绘制、MIT许可的几何鲸鱼SVG。
- 项目原创部分采用MIT；参考代码和QRCode.js分别保留完整MIT许可。
- SnowLuma路径由环境变量或相邻目录决定，不依赖原开发电脑路径。
- 语气指令默认空，额外增益默认0；自动分享、巡检与投稿默认关闭。
- 启动脚本仅启动WebUI，由其按规则托管业务，不额外重复启动Agent。

公开仓库：https://github.com/Huashan258/bili-whale-qq-public 。仅包含整理后的新提交，不含原私有历史。测试结果见 RELEASE_VALIDATION.md；上传源码不代表已验证全部外部API。
